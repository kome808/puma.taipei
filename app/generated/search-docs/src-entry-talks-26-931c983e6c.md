00:01:54毒品政策：除罪化、減害與戒治 趙趙少康你 2014 年的文章被拿來討論，現在是否主張毒品除罪化或大麻合法化？
沈沈伯洋我沒有要推毒品除罪化，也不主張大麻合法化。
舊文討論不同方案，我最後採取的是找出吸毒原因並處理成因；
販毒是犯罪，對有毒癮者則要談治療、教育與減害。
李李成穎我重新讀文章後，對 B、C 方案的理解和你剛才的說明不同。
當年的立場是否改變？
沈沈伯洋方案名稱與內容容易被混為一談。
我談的替代療法包括美沙冬與丁基原啡因，相關治療應在醫療體系進行；
也希望第一線人員不因政治攻防受到影響。
00:07:34校園防制：執法、拒絕技巧與早期轉介 趙趙少康如果當選市長，校園毒品與毒駕問題要怎麼處理？
沈沈伯洋我提出三個方向：校園附近販售熱點優先執法；
教孩子辨識壓力並練習拒絕；
若已經出現使用風險，透過 SBIRT 問卷辨識後轉介。
這不是唾液篩檢，而是問卷和後續協助。
00:10:14大罷免與社會撕裂：選戰回到政策討論 趙趙少康大罷免 32 比 0 未能成功，你支持這場運動，如何看策略與政治責任？
沈沈伯洋我是支持公民團體行使罷免權的人，也認為集中在少數指標選區有其道理；
但地方團體面對提高後的門檻，會擔心未來還有沒有機會。
意見不同不等於撕裂，我希望選舉講政見，不要斷章取義、貼標籤。

00:17:58雙城論壇：交流的前提、效益與風險 李李成穎你說既有交流框架可以保留，是否代表支持續辦雙城論壇？
沈沈伯洋框架可以留著，但要確保沒有政治前提、有實質內容、對產業有幫助；
若做不到，我認為不應舉辦。
交流要做風險控管，AI 主權、資安、情資刺探與機密保護的底線都要守住。
00:21:52跨國威脅：安全不是光榮表態 錢錢怡君你是否害怕遭監控？
赴日本穿防彈背心跑步，是必要防護還是作秀？
沈沈伯洋我不覺得被針對有什麼光榮不光榮；
公開人物應該注意風險。
住家附近的監控設備與案件進展，我已向警方反映並在節目中說明；
赴海外的防護安排，是對選民與家人的負責。
00:25:51不同立場的選民，都是溝通對象 錢錢怡君面對黃珊珊支持者與對大罷免不認同的藍白選民，你要如何爭取支持並成為全民市長？
沈沈伯洋我不會只想從某一個政黨挖票；
投給不同候選人的市民都是我要說服的對象。
若有人問我大罷免的理由，我願意重新說明，大家都是溝通對象。
00:32:39研究經費與 CIA 指控：回應不等於財務查核 趙趙少康外媒報導民間組織接受海外資助，另有 CIA 指控，你是否能說明經費來源與用途？
沈沈伯洋我不是 CIA 的人。
學者和智庫會申請國內外研究經費，機構經費用於研究、活動與研究人員人事；
我擔任台灣民主實驗室理事長不支薪，薪資來自台北大學教職。
記整理說明以上為節目提問與受訪者回應。
本頁未將雙方說法視為完整財務查核結果；
金額、資助來源與用途應另依公開資料核對。
00:35:54市政政策：營養午餐、內湖交通與執行結果 趙趙少康營養午餐加菜會不會造成比較？
內湖交通又該怎麼改善？
沈沈伯洋家長會加菜是全校一起提升食材，應以專法明定標準與補助。
內湖交通要把捷運、智慧號誌、自行車、彈性工時、通勤驛站與就近居住等方式疊加；
政策也要檢視不同群體實際能否受益。
00:43:37夜間市長：在衝突升高前先協調 錢錢怡君台北真的需要夜間市長嗎？
這個角色如何運作？

沈沈伯洋夜間市長不是單純管理治安，而是由代表夜間工作者的民間組織與市府對接，協調攤商、居民噪音與使用分區等衝突，在問題升高前建立溝通。
00:49:31死刑存廢：制度現況與程序保障 李李成穎你個人支持或反對廢死？
現行法律與你的長期理念是否一致？
沈沈伯洋長遠而言希望謹慎減少死刑使用，但目前台灣缺乏共識，現階段維持死刑制度。
審判程序必須極端嚴謹，避免冤獄與不公判決造成不可回復的傷害。
00:54:58防滲透與反標籤：保護和透明並行 錢錢怡君談滲透風險時提到里長、宮廟、立委與中配，會不會造成身分標籤化？
保護和管制如何區分？
沈沈伯洋我沒有說中配是高風險；
中配與台商可能是受威脅的被害人，應該建立保護而非處罰機制。
里長私人交流和公務交流可有不同風險管理與通報程序，規則公開透明才能減少任意質疑。
我理解標籤化已造成傷害，也會努力把論述說清楚。
趙趙少康好，講清楚最重要。
