# 沈伯洋政策分享蒟蒻第一版實作計畫

> For agentic workers: use superpowers:subagent-driven-development. Ownership is split between corpus, frontend, and backend; preserve all parallel changes.

**Goal:** 將現有政策與訪談快照接成實際可用的兩項服務，所有可複製稿含來源網址與換行不超過 500 字元。

**Architecture:** React/Vite 前端與 Workers API；R2 保留語料，D1 保存可引用來源、分段及不含原始輸入的用量資料；AI Search 提供受管理的檢索，D1 中文關鍵字檢索作可辨識的備援；使用 OpenAI Responses API 的 gpt-6-luna 產文。原始快照不修改。

**Tech Stack:** TypeScript, React, Vite, Cloudflare Workers/D1/R2/AI Search, OpenAI Responses API.

## 已確認的產品設計

- 主入口「分享政策」，次入口「社群回應幫手」。輸入主題／他人留言，檢索原文，產生段落式草稿，再編輯與複製。
