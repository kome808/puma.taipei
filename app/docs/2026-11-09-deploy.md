## 步驟（在 `app/` 目錄，失敗就停）

### 0. 取得分支與確認登入

```sh
git fetch origin claude/kind-cerf-xyiajt && git checkout claude/kind-cerf-xyiajt && git pull
cd app && npm ci
npx wrangler whoami      # 應為 kome808@gmail.com、帳戶 4c10afbddf5fd32960496609cc2061d0
```

### 1. 測試與建置（同一次建置的產物要一起發布）

```sh
npm test                 # 2026-11-09 雲端結果：126 項全過
npm run build            # Worker 用的 dist，並產生 generated/topic-search-data.sql
npm run build:static     # Pages 用的 static-dist
python3 -I scripts/apply-summary-500.py | head -4    # status 應為 passed
```

確認 `static-dist/topics/data.json` 的 `semantic_corpus_version` 與 `generated/topic-search-data.sql` 最後一行的 `corpus_version` 相同；不同就重新跑 `npm run build:static`，不要混用不同次建置的檔案。

### 2. 遠端 D1：補表並匯入主題索引

```sh
npx wrangler d1 execute puma-policy-v1 --remote --file worker/runtime-schema.sql
npx wrangler d1 execute puma-policy-v1 --remote --file generated/topic-search-data.sql
npx wrangler d1 execute puma-policy-v1 --remote --command "SELECT value FROM topic_search_meta WHERE key='corpus_version'"
npx wrangler d1 execute puma-policy-v1 --remote --command "SELECT COUNT(*) FROM policy_topic_fts WHERE corpus_version=(SELECT value FROM topic_search_meta WHERE key='corpus_version')"
```

- 第一個指令全用 `IF NOT EXISTS`，不動既有語料、`request_limits`、`generation_usage`。
- 第二個查詢必須正好是 86：程式會檢查版本與題數，多於或少於 86 時基本搜尋會停用並顯示「基本搜尋目前無法提供服務」。
- 若遠端回報不支援 `BEGIN TRANSACTION`，先產生一份去掉首尾 `BEGIN TRANSACTION;`、`COMMIT;` 兩行的副本再匯入：`grep -v '^BEGIN TRANSACTION;$\|^COMMIT;$' generated/topic-search-data.sql > generated/topic-search-data.remote.sql`。版本指標寫在檔案最後，所以中途失敗不會切換到不完整的版本；重跑同一檔會再插一份同版本資料，因此失敗後要先回報，不要直接重跑。
- 不要執行任何 `--reset-corpus`、`DELETE` 或舊的 `cloudflare-import-d1.mjs`。

### 3. 更新 Worker `puma-policy-v1`（停止舊 API）

```sh
npx wrangler deploy
curl -s -o /dev/null -w "%{http_code}\n" -X POST https://puma-policy-v1.kome808.workers.dev/api/generate   # 410
curl -s -o /dev/null -w "%{http_code}\n" "https://puma-policy-v1.kome808.workers.dev/api/search?q=test"    # 410
curl -s https://puma-policy-v1.kome808.workers.dev/api/health   # mode: static-topic-search
```

記下新的 Worker 版本 ID。Worker 上原有的 Secret 與 D1／R2 不會被刪；`wrangler.jsonc` 已移除 AI Search binding 與模型變數。

### 4. 發布 Pages `puma-note`（取代舊 gateway）

```sh

../app/node_modules/.bin/wrangler pages deploy ../app/static-dist --project-name puma-note --branch main --no-bundle
```

從 `pages-static/` 執行，讓它讀到該目錄的 `wrangler.jsonc`（D1 binding、語意關閉）。不要用 `pages-search/`、`app/pages-gateway/` 或舊的 `build-pages-gateway.mjs`。記下新的 Pages 部署 ID。
