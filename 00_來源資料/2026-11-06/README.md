## 檔案用途

| 位置 | 用途 |
|---|---|
| `官方政策/` | 官方原始 HTML、可讀 Markdown、政策圖片、附件及分組清單 |
| `訪談逐字稿/raw/html/` | 訪談與逐字稿的原始 HTML |
| `訪談逐字稿/raw/attachments/` | 來源網站提供的原稿或文章附件，保留下載原始位元組 |
| `訪談逐字稿/text/` | 可讀文字導出版或原始文字附件的本機副本 |
| `訪談逐字稿/entries.json` | 每個入口對應的文章、逐字稿、附件及影音連結 |
| `訪談逐字稿/coverage.json` | 找到逐字稿的方式、缺漏及下載失敗項目 |
| `官方政策/coverage.json` | 政策索引項目、圖片／附件對應、下載範圍與限制 |
| `工具/` | 下載、來源清單整合及完整性檢查程式 |

原始 HTML 與下載附件是保存原貌的依據。Markdown 是方便閱讀的導出版，會省去樣式、導覽等版面結構；原始 HTML 的顯示仍可能需要線上樣式與腳本，本資料包不是完整離線網站鏡像。

## 內容狀態與後續使用

- 來源中的自動轉錄錯字、缺句、原始日期與「尚未核對影音」警語保留，不在下載時改寫。官方政策、訪談說法、整理文章與原稿附件以 `kind` 區分。
- 逐字稿狀態依頁面內容與可下載來源判定，並非逐句影音校對，也不保證訪談稿包含未公開的對話。
- 圖片與 PDF 原檔已列入來源清單；未進行圖片 OCR 或 PDF 全文抽取，因此二進位附件的內容不會自動出現在全文 JSONL。
- `全文資料.jsonl` 包含同一訪談的不同來源版本，可能有重複段落。後續問答開發需保留入口關聯、來源日期與不確定性，不把重複版本當成多份獨立證據。
- 各來源的授權說明保留於原頁與導出版；不同來源不可直接假定使用相同授權。
